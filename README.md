# Portfolio_Website


# 🌐 Portfolio Website

A modern and responsive personal portfolio website built to showcase my projects, technical skills, experience, and achievements in Full Stack Development, Android Development, and AI/ML.

---

# 🚀 About the Project

This portfolio website was developed to create a professional online presence and highlight my work, technical expertise, and real-world projects. The website includes sections for projects, skills, experience, education, achievements, and contact information with an integrated email contact system.

The portfolio is designed with a clean and modern UI, responsive layouts, smooth animations, and interactive components to provide an engaging user experience.

---

# ✨ Features

* Responsive modern UI
* Dark/Light mode support
* Smooth animations using Framer Motion
* Project showcase section
* Skills and experience timeline
* Contact form with email integration
* GitHub and LinkedIn integration
* Interactive chatbot component
* Optimized and scalable React structure

---

# 🛠️ Tech Stack

## Frontend

* React.js

## Backend / Services

# ⚡ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/DhruvHedaoo2704/Portfolio_Website.git
```

## Navigate to Project Folder

```bash
cd Portfolio_Website
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```
